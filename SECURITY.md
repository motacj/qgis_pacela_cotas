# Security policy

## Supported version

Security fixes are applied to the latest published version of the plugin.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.
Contact the maintainer at `atom.susej@gmail.com` and include the affected
version, reproduction steps and expected impact. Do not include credentials,
private parcel data or personal information.

The plugin performs local processing only. It does not use network services,
telemetry, credentials or external Python packages.
